【失败项与缓解措施】
  A. QMP 无 sendkey 命令（HMP 独有），首轮 T6 两轮无效
     → 缓解: 增加 HMP TCP 通道；Qmp.cmd 改显式抛错；SeaBIOS F12 隔离
       测试定位。Agent 输入模块零缺陷。
  B. OVMF SB 固件首启停在 640x480 单行文本屏（与 VARS/签名无关）
     → 缓解: 矩阵排除法确认需 -machine q35,smm=on + secure pflash
       （edk2 SB 构建标准要求，P1 文档遗漏，已记入环境报告）。
  C. virt-fw-vars --enroll-generate Windows tempfile 缺陷
     → 缓解: openssl 三级证书链（PK→KEK→DB + codeSigning EKU）+
       --set-pk/--add-kek/--add-db 显式注入（含 keyCertSign 拼写修正）。
  D. T5b 720p 黑屏（仅 4MB 显存合成场景）
     → 定性: QEMU std-vga 模型怪癖；降级判定与安全退出不受影响；
       真机不存在此配置。记入已知限制。
  E. 化妆瑕疵（非失败）: T7 错误提示 target 行显示常量默认路径，非
     config 实际配置路径 → P5 评审项（一行修复，不影响行为）。
